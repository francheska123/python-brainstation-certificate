# Python Brainstation Certificate

#### 🐍 Focus Area: Data Analysis using Python.

Period: Mar - Apr 2025

#### 🧠 Core Concepts Learned
- Python Syntax & Programming Fundamentals: Variables, expressions, data types, and control flow.
- Data Structures: Lists, dictionaries, loops, and functions.
- Problem Solving & Logic: Writing reusable code to analyze and interpret structured data.
- Jupyter Notebook & Jupyter Lab: Used as the main environment for writing, testing, and documenting Python code.

- Libraries Used: Pandas, NumPy, Matplotlib.

- Exploratory Data Analysis (EDA): Created pivot tables, summary stats, and basic plots to uncover insights.
